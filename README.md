# 人格切换（astrbot_plugin_persona_switcher）

让**用户**在聊天里自己换人格，但只能换成**管理员在后台勾选过**的那几个。

- 后台可视化勾选：插件详情页里直接勾「哪些人格允许被用户切换」，不用手打 ID
- 用户侧指令：`/人格`、`/人格切换 2`、`/人格当前`、`/人格重置`
- 会话级隔离：A 群切成猫娘，不影响 B 群和私聊
- 与 AstrBot 原生人格互通：WebUI「会话管理」里能看到同一个人格，下一条消息立即生效
- 零第三方依赖：只用 AstrBot 自带的 Persona / 会话存储，不需要 Redis、外部 API 或额外 Python 包

## 安装

要求 AstrBot **4.16 及以上**（4.x）。

仓库安装（推荐）：

```text
https://github.com/Geekertao-Studio/astrbot_plugin_persona_switcher
```

WebUI → 插件 → 从仓库安装，填上面的地址；或把本目录放进 `AstrBot/data/plugins/` 后重载插件。

装好后在插件列表里点开「人格切换」，进入「可切换人格」设置页勾选即可。

## 后台设置

插件详情页的可视化面板：

- **允许使用全部人格**：开启后不限制，任何人格都能切（默认开启，装完即可用）
- **可切换人格**：关闭「全部人格」后，只有勾选的人格会出现在用户列表里

同样的设置也在插件配置页里（`allowed_personas` 是人格 ID 列表），两个入口改的是同一份配置。

其他配置：

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `admin_only_switch` | 关 | 只有管理员能切换，普通用户只能看列表 |
| `allow_private_chat` | 开 | 是否允许在私聊切换 |
| `allow_group_chat` | 开 | 是否允许在群聊切换 |
| `clear_context_on_switch` | 关 | 切换时清空当前会话上下文，避免旧人格的对话残留 |
| `show_prompt_preview` | 关 | 列表里附带人格提示词前 60 字（含私密设定时别开） |
| `max_list_items` | 20 | 聊天里一页最多显示多少条 |

## 指令

| 指令 | 别名 | 说明 |
| --- | --- | --- |
| `/人格` | `/persona` `/人设` | 帮助与入口 |
| `/人格列表` | `/人设列表` | 列出可切换人格（当前那个会标出来） |
| `/人格切换 <编号或ID>` | `/人设切换` `/切人格` | 切换到指定人格，也支持直接 `/人格 2` |
| `/人格当前` | `/人设当前` | 查看当前会话的人格 |
| `/人格重置` | `/人设重置` | 清除会话人格，回到默认 |
| `/人格允许 <编号\|ID\|全部>` | — | 管理员：加入可切换列表 |
| `/人格禁止 <编号\|ID\|全部>` | — | 管理员：移出可切换列表 |

示例：

```text
用户：/人格
机器人：可切换人格：
        1. default — 你是一个乐于助人的助手。
        2. 猫娘 — 你是一只黏人的猫娘……
        3. 正经助手 — ……
        用法：/人格切换 <编号或人格ID>

用户：/人格切换 2
机器人：已切换人格为「猫娘」，下一条消息生效。
```

## 与「现成插件」的区别

写这个插件前翻过 AstrBot 插件市场里的人格类插件（2026-11 数据）：

- `persona_plus`（约 1.2k 下载）：功能很全，但「谁能切哪些」主要靠指令/关键词，不是后台勾选
- `persona_switch` 系列（几十下载）：大多只能全量切换，或者要在配置里手打人格 ID 白名单
- 其余多为「按关键词/情绪自动切」或「陪伴向人格演化」，不是「管理员圈定范围、用户自主切换」

所以这个插件的定位很窄：**后台勾选范围 + 用户自助切换 + 会话级隔离**，不碰人格内容生成，也不接管对话流程。

## 实现说明

- 读取人格：`PersonaManager.get_all_personas()`
- 切换：`ConversationManager.update_conversation(persona_id=...)`，同时写入会话覆盖
  （`agent.config.persona.persona_id`），所以 WebUI 与插件看到的是同一份状态
- 重置：清掉会话覆盖，并把会话的 `persona_id` 置空，回到全局默认
- 设置存储：插件配置 `data/config/astrbot_plugin_persona_switcher_config.json`
- 没有任何后台轮询或外部请求

## 已知边界

- 只影响走 AstrBot agent / LLM 流程的回复；别的插件自己硬编码的提示词管不到
- 「重置」回到的是当前会话的默认人格（全局配置里的那个），不是插件另存的某个快照
- 人格 ID 就是 WebUI 里的人格标识；重命名人格后，白名单里的旧 ID 会失效，需要重新勾选
